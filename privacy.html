Privacy Policy

Last updated: October 23, 2026

1. What this application does

DSH Mail Assistant is a personal-use desktop application that helps its developer manage their own email account(s). It sends outgoing emails through the owner's mailbox and reads incoming messages (replies, out-of-office auto-responses, and delivery failure notifications) so that correspondence can be organized in one place. The application is not distributed to the public and is not intended to access any account other than the developer's own.

2. Data we access

With the account owner's explicit authorization through Google's OAuth consent screen, the application requests the following read-only/minimal Gmail API scopes:

  • gmail.readonly — to read incoming messages, replies and bounce notifications in the authorized mailbox
  • gmail.compose — to create draft emails
  • gmail.send — to send emails from the authorized mailbox

The application does not access Gmail data of any other user, and does not request access to Contacts, Calendar, Drive, or any other Google services.

3. How data is used

Email content accessed by the application is used exclusively to provide the functionality described above: displaying correspondence status to the account owner and organizing replies and bounce notifications. The application follows Google's API Services User Data Policy including the Limited Use requirements. Data is never sold, shared with, or transferred to third parties for advertising or any unrelated purpose. No human ever reads the mailbox content except the account owner themselves.

4. Data storage

All data processed by the application stays on the owner's local computer. OAuth tokens are stored locally in a protected credentials file. The application does not operate any external server, does not upload email content to any database, and does not create remote copies of your data.

5. Data deletion

You remain in full control of your data at all times:

  • To revoke the application's access to your Google account, visit https://myaccount.google.com/permissions, select this application and click Remove Access. Revocation takes effect immediately and all stored tokens become invalid.
  • To delete locally stored tokens and records, simply delete the application's credentials folder on your computer.
  • Deleting an email in Gmail removes it permanently in accordance with Gmail's own retention rules.

6. Third-party services

This application interacts solely with the Google Gmail API. Google's own handling of your data is governed by Google's Privacy Policy. The application does not integrate any analytics, advertising, or tracking services.
